# Projeto Integrador - Catálogo de Produtos Artesanais

Este projeto é um catálogo digital para uma loja fictícia de produtos artesanais.
O objetivo é apresentar os itens disponíveis, com fotos, descrições e preços,
facilitando a divulgação do trabalho de pequenos artesãos.
Será desenvolvido ao longo da disciplina como Projeto Integrador.
