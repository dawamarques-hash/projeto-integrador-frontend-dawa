# Projeto Integrador Front-end - FuteVibe

Loja virtual especializada em artigos para praticantes de futevôlei, com produtos como bolas, redes, roupas esportivas, shorts, camisas, óculos, bonés e acessórios em geral.

O objetivo deste projeto é apresentar um site funcional e responsivo onde o público-alvo (praticantes e entusiastas do futevôlei) possa conhecer e visualizar os produtos oferecidos.

Este repositório documenta o desenvolvimento do Projeto Integrador do curso de Análise e Desenvolvimento de Sistemas.
